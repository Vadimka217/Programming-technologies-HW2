This project is a homework assignment for a programming technology course. The development history can be seen in the commits. The code from the Jupiter laptop was copied to a Python file for easy deployment, and the tests are written in a separate Python file.

To download project you should enter the next commands at the command line:

```bash
git clone https://github.com/Vadimka217/Programming-technologies-HW2.git
cd HW2_OOP_Testing_Git
pip install -r requirements.txt
pytest
```

To run tests, you need to install Pytest using the following command:

```bash
pip install -r requirements.txt
pytest
```
